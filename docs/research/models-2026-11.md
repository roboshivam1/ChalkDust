# Open-weight models for ChalkDust, November 2026

Research date: 17 November 2026. This file answers one question: which open-weight LLMs to use right now for ChalkDust's three LLM jobs (lesson plan, narration, component-param JSON), on each machine tier, and which ones can legally act as a teacher for distillation into a model shipped in a paid app.

Every model fact below comes from a page fetched on 17 November 2026; the URL is in the Sources list at the end. Anything marked **[unverified]** was not confirmed from a primary source. All benchmark numbers are **vendor-reported on the vendor's own card** unless stated. Numbers from different cards are not comparable: for example, Qwen's card gives Qwen3.5-4B 59.2 on IFBench, while Liquid's LFM3 card gives the same model 38.16. Compare models within one card, never across cards. **Nothing here was measured on ChalkDust's machines.** Every tokens-per-second figure comes from other hardware.

## 1. Outcome summary

1. **Machine A (RTX 5070 Ti laptop, 12 GB VRAM + 32 GB RAM):** run **Qwen3.6-35B-A3B** (Apache-2.0, 35B total, 3B active), Unsloth UD-Q4_K_M at 22.1 GB, with MoE experts offloaded to RAM. Use **Qwen3.8-27B** (Apache-2.0, August 2026) when the lesson plan needs top quality and speed matters less.
2. **Machine B (MacBook M1, 16 GB):** run **Qwen3.5-9B** (Apache-2.0), Q4_K_M at 5.7 GB. It is the only candidate with a measured M1 16 GB number: 10.9 to 12.6 tok/s generation and 64 to 76 tok/s prompt processing with MLX 4-bit. [corrected 2026-11-17: across the two oMLX pages the measured ranges are 10.5 to 12.6 tok/s generation and 63.5 to 76.5 tok/s prompt processing. MLX peak memory was 5.7 GB at 1k context, 6.3 GB at 4k and 6.7 GB at 8k, so the 5.68 GB GGUF file size and the runtime footprint are different numbers.] A 4k-token prompt therefore costs about a minute before the first token [corrected 2026-11-17: this was measured, not only inferred: time to first token at 4k was 53,981 ms on the 8-core M1 page], so prompt caching matters on this tier.
3. **Machine C (8 to 16 GB RAM, CPU or iGPU):** run **Qwen3.5-4B** (Apache-2.0, Q4_K_M at 2.7 GB) or **Granite 4.2 3B** (Apache-2.0, Q4_K_M at 2.3 GB). No laptop-CPU speed was found for either. For the lesson plan on this tier, default to the paid cloud option.
4. **Recommended teacher:** **Qwen3.8-27B** for quality and **Qwen3.6-35B-A3B** for volume. Both are Apache-2.0, run on machine A, and leave the outputs free for commercial distillation. Add **Gemma 4 26B-A4B or 31B** (Apache-2.0) as a second-family teacher for diversity.
5. **Recommended student:** **Qwen3.5-4B**. It is Apache-2.0, bf16 LoRA needs 10 GB per Unsloth (so it fits the 12 GB GPU), Unsloth supports GRPO on it, and Amazon already fine-tuned Qwen3.5-2B into a shipped decision model [corrected 2026-11-17: it is an open-weight release from AWS's Strands Labs, a LoRA plus readout head on Qwen3.5-2B-Base per its card. Press coverage dates it to 1 Oct 2026 and calls it an experiment rather than a product (seen in search results only: unverified)]. Run a bake-off against **Granite 4.2 3B** (Apache-2.0, plain dense transformer, strong IFBench and AIME on IBM's card).
6. **Licences to avoid as teacher or base:**
   - Llama 4 forces "Llama" at the start of the student's name.
   - The Gemma Terms (Gemma 1 to 3n, not Gemma 4) treat models trained on Gemma outputs as Model Derivatives. [corrected 2026-11-17: the Terms cover every model in their Appendix, which has 24 entries (FunctionGemma appears twice): Gemma 1 to 3n plus PaliGemma, CodeGemma, ShieldGemma, RecurrentGemma, EmbeddingGemma, FunctionGemma, T5Gemma 2, VaultGemma, TranslateGemma and others. Only Gemma 4 is excluded.]
   - The LFM Open License v1.0 forbids commercial use once revenue reaches $10M a year.
   - The Qwen Community License 1.0 (Qwen3.8-Flash-Next only) needs a separate licence for "Model as a Service" businesses, which ChalkDust's paid cloud tier could fall under. [corrected 2026-11-17: the definition is narrower than this suggests. It covers access to inference or fine-tuning "in a manner that allows such third parties to exercise meaningful control over the inputs, parameters, or training data". A tier where students only submit a topic may fall outside it. That is a question for a lawyer, not settled here.]
7. **Apple's on-device model is not a foundation to build on.** The adapter-training toolkit 26.0.0 "is the last release" and does not work on OS 27. The on-device context is 8,192 tokens [corrected 2026-11-17: 8192 is only the printed output of a WWDC26 code sample. Apple's framework documentation states no fixed on-device context size, and the talk says to read `contextSize` at runtime].
8. **Phi Silica is not shippable today.** It needs a Limited Access token and is removed in January 2027, when Aion Instruct replaces it. Its GPU path needs Developer Mode on an Insider build. **Foundry Local** is shippable in-process with no token, but it runs Microsoft's catalogue on ONNX Runtime GenAI. Whether it can load ChalkDust's own GGUF student is [unverified].
9. **Specialised "decision models" have appeared** (Strands Decider 2B and Cloudflare Clef-flash 9B, both Apache-2.0; Liquid d1-2B under the LFM licence). They pick from given options in a single forward pass. That fits ChalkDust's "which of 20 components" step and validator-style judging. [corrected 2026-11-17: newer Strands checkpoints exist, including Gemma-4-based ones; see section 7.] They cannot fill params: use grammar-constrained decoding in llama.cpp for that.
10. **Too big for any target machine, but MIT-licensed teachers if you rent GPUs:** GLM-5.3-Flash (321B, 18B active) and DeepSeek-V4.1-Flash-1017. **Qwen3.8-Flash-Next does not fit machine A**: its smallest listed quant, UD-IQ2_XS, is 75.8 GB.

**Speed evidence for tier A (other hardware only):**

- One measured run used Qwen3.6-35B-A3B UD-IQ3_XXS (13.2 GB) on an **RTX 3060 12 GB + 31 GB DDR4 + Xeon E5-2650 v4**, with `-ncmoe 25`, q8_0 KV cache and 64k context. It reached **22.9 tok/s** generation, using 7.1 GB of VRAM and 7.7 GB of RAM. Without the flag it ran out of memory.
- The same post cites an RTX 3070 Ti 8 GB at 40.9 tok/s.
- The 5070 Ti laptop has a newer GPU; its RAM type and speed were not checked. It should do at least as well, but **this is unmeasured**. Run `llama-bench` with several `--n-cpu-moe` values on machine A before relying on any number.

**Recommendation for A:** use Qwen3.6-35B-A3B for all three jobs. Fall back to Gemma 4 12B fully in VRAM when Manim needs the GPU memory or when latency matters more than quality.
